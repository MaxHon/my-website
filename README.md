# 衡渡｜跨境財富規劃原型

一個不需第三方套件的概念原型，透過本機 Node.js 代理呼叫對話 API。

## 快速體驗

在專案根目錄建立 `.env`，填入服務商的新密鑰（不要將密鑰傳到瀏覽器或提交到 Git）：

```env
JUHE_API_KEY=your-new-key
JUHE_MODEL=gpt-5.5
```

然後執行 `npm start`，瀏覽器打開 `http://127.0.0.1:4173`。不要用 `file://` 直接打開 HTML，因為 AI 請求需要經由本機代理。

流程體驗：

1. 回答 3 題，得到初步風險取向。
2. 輸入大約金額、年期，選擇回報目標、關注模組及一個預設方案。
3. 生成配置比例、簡化情境示意和下一步討論問題。
4. 在結果頁詢問 AI；送出的內容包含匿名規劃摘要及你的問題，請勿輸入可識別身份的資料。

## 目前呈現的簡單產品計劃

- **流動守成**：銀行定期 50%、基金 25%、保障 25%。
- **平衡成長**：銀行定期 30%、基金 45%、保障 25%。
- **長線增值**：銀行定期 15%、基金 65%、保障 20%。
- 傳承規劃作為獨立的需求檢視模組，不佔投資配置比例。

`server.mjs` 從 `.env` 讀取服務密鑰，提供 `/api/plan-insight` 本機代理。上游 URL 和請求格式目前依 OpenAI 相容 Chat Completions 方式暫設；因接口文件端點無法核實，實際使用前請確認服務商文件要求。如需更改 API 端點，編輯 `server.mjs` 中的 `apiUrl`。比例只在勾選的銀行定期、基金、保險模組之間重新正規化。情境年化數字是前端示意常數，並非產品回報或投資建議。正式產品化前應由持牌/合資格專業人士確認風險評估、產品資料、計算口徑、個人資料、跨境稅務及各地監管合規要求。

## 文件

- `index.html`：語義化頁面、流程和文案。
- `styles.css`：響應式視覺樣式。
- `app.js`：風險計分、方案選擇、配置重算及摘要複製。
- `server.mjs`：本機 API 代理與靜態檔案伺服器。
- `.env.example`：本機密鑰設定範本；真實 `.env` 不應提交。
